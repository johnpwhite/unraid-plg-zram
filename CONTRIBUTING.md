# Contributing to unraid-plg-zram

Thank you for your interest. This page explains how the project works, so that you know what to expect.

## How the project works

- The owner develops this plugin in a private repository.
- This GitHub repository is a public copy. It is updated for each release.
- Only tagged commits (`vYYYY.MM.DD.XX`) are releases. A commit between two tags may not work on its own.
- The folder `src/assets/ui` is built code. Do not edit it by hand.

## Report a bug or ask for a feature

Open an issue. Use the issue templates in `.github/ISSUE_TEMPLATE`. An issue is the best way to help.
Say what you did, what you expected, and what happened. Attach a support bundle if the plugin can make one.

## Send a pull request

We read every pull request and we reply on it.

- We do not merge a pull request on GitHub. The project lives in the private repository.
- If we accept your change, we port it into the private repository. The commit has a `Co-authored-by` line with your name.
  Your name then shows in the public history of the next release.
- We close a pull request only with a comment. The comment says why, or names the release that contains your change.
- For a large change, open an issue first. We can then agree on the idea before you write the code.
